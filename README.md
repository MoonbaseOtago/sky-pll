# Tiny Tapeout PLL

- [Read the documentation for project](docs/info.md)


This is a test 'chip' for a Tiny Tapeout PLL - it's a 1x1 tile wide though probably more useful in larger
projects, the output is intended for 50-200MHz but may work up 300MHz. This way you can have a 200MHz
cloxk for your Tine Tapeout projects.

Again this is a TEST, "works under spice" is not the same as "works"
